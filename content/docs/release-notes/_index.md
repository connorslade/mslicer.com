Release notes give an overview of the biggest and most interesting changes and features added in a release in a visual way.
You can also view the [changelog](/docs/changelog) for a straight list of everything changed.
Note that older versions don't have release notes, so check the changelog.

I try to make a release approximately monthly when I'm working on the project.
